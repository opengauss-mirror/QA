# QA

#### Introduction

- Formulate version test policies: Define the scope and key points of new feature tests, specify test specifications, discuss the entry and exit criteria, and identify potential risks.
- Execute version test tasks: Develop and execute test plans and cases, test important system functions, carry out special test activities, and output version test reports.
- Develop test tools: Develop and run attacks to automatically discover potential defects.
- Maintain release criteria: Maintain release criteria with developers and release engineers. The release criteria are used to determine which defects should be fixed before the pre-release or final release of the openGauss.
- Carry out industry insight and research on database testing.

#### Meetings

- Public meeting time: 15:00–17:00 (GMT+08:00) every other Friday
