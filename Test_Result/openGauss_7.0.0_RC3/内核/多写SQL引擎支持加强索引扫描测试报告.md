**Keywords 关键词**：多写SQL引擎

**Abstract 摘要**：支持计划层中对[not]between,[not] in [!]=true or false [not]like， is [not] null操作符的适配，增加对上述操作符的适配可以令计划层的预估rows更为准确，令后续生成合成路径中的预估行数与代价更贴近实际，通过帮助计划层中后续生成更准确的合成代价，从而指导优化器生成更加高效的查询计划。通过在目标环境中测试，该特性表现符合预期，整体测试质量优秀。
