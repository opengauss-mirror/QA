本阶段完成了重分布函数的功能测试、资料测试，需求特性100%实现。本次测试执行用例17个，发现问题1个，开发质量良好

## 3.2 约束说明

1.CN主节点修改postgresql.conf

```
password_encryption_type = 1
shared_preload_libraries = 'spq'
enable_pbe_optimization = OFF
```

2.DN节点修改postgresql.conf

```
password_encryption_type = 1
shared_preload_libraries = 'spq'
```

3.DN节点修改pg_hba.conf

```
host	all	all	CN节点IP/32	trust
```

4.所有节点都需要执行sql：

```
create extension spq;
```
