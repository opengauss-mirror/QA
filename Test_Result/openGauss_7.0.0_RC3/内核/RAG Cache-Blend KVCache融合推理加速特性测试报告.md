**Keywords 关键词**：RAG KVCache

**Abstract 摘要**：使用openGauss-sqlalchemy（适配SQLAlchemy框架的OpenGauss方言库）异步连接LMCache和openGauss数据。一次长序列LLM问答会在短时间发送10+SQL读请求，使用异步+连接池模式支持并发查询，优化耗时2+秒。适配CAKE方案，实现计算和复用KV并行运行。通过在目标环境中测试，该特性表现符合预期，整体测试质量优秀。
