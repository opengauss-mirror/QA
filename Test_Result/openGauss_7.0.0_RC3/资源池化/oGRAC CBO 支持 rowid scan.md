# 3 版本概要测试结论、关键风险和规避措施

## 3.1 测试结论总结

oGRAC支持rowid scan特性，共计执行了7个用例，主要覆盖了功能测试。
功能测试主要包括两方面生成表条件扫描计划和生成索引扫描计划。每个方面均包括了单条件和多条件(组合条件)，其中单条件包括条件运算符、数值处理函数。条件运算符涵盖了基础比较运算符、范围运算符、模糊匹配运算符、逻辑运算符、高级条件运算符，数值处理函数涵盖了取绝对值、四舍五入、向上取整、向下取整、取余数、取平方根、取n的m次方、截断小数。另外测试内容还包含了非nested loop的join连接场景，包括hash join、merge join的反测试用例。

测试中没有发现问题，整体质量良好。

## 3.2 约束说明

- 仅支持nested loop
