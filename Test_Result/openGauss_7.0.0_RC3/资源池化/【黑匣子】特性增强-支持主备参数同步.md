# 1 概述

本报告主要测试oGRecorder集群配置参数同步能力，包含：重启生效类参数、设置立即生效类参数、单节点生效类参数分别对各类场景进行正常和异常场景验证测试，各类参数设置场景中注入进程异常、网络故障测试验证其可靠性场景。
