# 1 概述

*本报告是 openGauss 数据库 7.0.0-RC3.B019 版本“支持pg_matviews系统视图”特性测试活动的总结。被测对象为数据库内核中新增的 `pg_matviews`系统视图及其相关的物化视图、增量物化视图管理功能。测试旨在验证该视图能否正确记录和反映数据库中所有物化视图的元数据信息。*

# 3 版本概要测试结论、关键风险和规避措施

## 3.1 测试结论总结

openGauss的pg兼容模式下，实现支持pg_matviews视图功能，共计执行26个用例，主要覆盖了物化视图与增量物化视图的视图创建、索引状态跟踪、表空间信息、ALTER操作同步、删除清理、权限控制、模式兼容性、升级回退等全部设计场景，通过手工执行用例，测试过程中未发现缺陷，所有功能行为符合设计预期。整体质量良好。

## 3.2 约束说明

**ALTER MATERIALIZED VIEW ... SET TABLESPACE** 操作当前版本不支持。执行该语句不会修改物化视图的物理存储位置，`pg_matviews`中的 `tablespace`字段保持不变。此为已知设计限制。

**ALTER MATERIALIZED VIEW ... SET SCHEMA** 操作当前版本不支持。无法通过DDL语句更改物化视图所属的模式，`pg_matviews`中的 `schemaname`字段保持不变。此为已知设计限制。
