# 3 版本概要测试结论、关键风险和规避措施

## 3.1 测试结论总结

​        opengauss兼容A库下支持xmltable函数，共计执行35条用例，主要覆盖功能测试，性能测试和不同数据库的兼容性测试以及升级测试。第一，功能测试。在功能测试中首先覆盖在支持xmltable函数的情况下，参数的多样性，包括passing xmldata的不同形式，COLUMNS的多种情况以及path中可能涉及到的不同情况；其次是关于xmltable函数对于语法的基础解析，包括解析xml文件，深层嵌套解析，空节点值解析这种情况；最后还有一些扩展情况的功能测试，主要包括与join的结合情况，与聚合函数的结合情况还有多行数据解析以及将解析结果写入表等这种扩展的情况。第二，性能测试。性能测试主要就是在大数据量的情况下，进行插入大量xml数据，测试其解析性能以及在并发情况下看函数的表现。第三，兼容性测试。兼容性测试主要涉及在不同数据库中语法的兼容情况。第四，升级测试。从不支持使用xmltable函数的版本升级到支持xmltable函数的数据库版本并能正常使用xmltable函数。最终在功能测试中发现了两个问题，主要涉及嵌套标签的解析以及多行相同标签数据的解析，问题已提单。
