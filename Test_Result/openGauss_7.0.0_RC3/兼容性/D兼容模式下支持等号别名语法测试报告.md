# 3 版本概要测试结论、关键风险和规避措施

##  3.1 测试结论总结

​        openGauss 数据库D兼容模式下支持等号别名语法 ，共计执行了57个用例，主要覆盖了功能测试、其他表类型测试、异常测试、兼容性测试、其他场景测试、升级测试以及资料测试。测试覆盖了参数设置测试、别名使用测试以及带模式名测试、不同表类型测试、异常使用测试等，测试中发现未发现问题，整体质量良好.

## 3.2 约束说明

- 仅支持在D模式下使用且手动创建shark插件后使用
- 别名不支持单引号包裹，可使用更通用的双引号或方括号包裹。
- 默认按照别名语法解析

## 3.3 关键风险和规避措施
