**Keywords 关键词**：GMS_XMLPARSER插件

**Abstract 摘要**：兼容性能力提升，包括以下常用函数：

- PARSE函数用于将XML字符串解析为XML数据类型，并关联到之前创建的解析上下文。
  - gms_xmlparser.parse(parser gms_xmlparser.parser, str varchar2)
  - gms_xmlparser.parse(str varchar2)
- NEWPARSER函数用于返回一个新的解析器实例
  - gms_xmlparser.newparser()
- FREEPARSER函数用于释放解析器对象。
  - gms_xmlparser.freeparser(parser gms_xmlparser.parser)
- GETDOCUMENT函数用于获取DOM文件。
  - gms_xmlparser.getdocument(gms_xmlparser.parser)
- PARSEBUFFER函数用于解析给定BUFFER的XML文件。
  -  gms_xmlparser.parsebuffer(parser gms_xmlparser.parser, str varchar2)
- PARSECLOB函数用于解析给定的CLOB的XML文件。
  - gms_xmlparser.parseclob(parser gms_xmlparser.parser, str varchar2)

##  3.1 测试结论总结

​        openGauss 数据库常用插件gms_xmlparser ，共计执行了53个用例，主要覆盖了功能测试、资料测试。功能测试覆盖了插件函数的基本功能，第一，PARSE函数将XML字符串解析为XML数据类型，并关联到之前创建的解析上下文的测试验证。第二，NEWPARSER函数返回一个新的解析器实例的测试验证。第三，FREEPARSER函数释放解析器对象的测试验证。第四，PARSEBUFFER函数解析给定BUFFER的XML文件的测试验证。第五，PARSECLOB函数解析给定的CLOB的XML文件的测试验证。第六，GETDOCUMENT函数获取DOM文件的测试验证。测试中发现1个问题，整体质量良好.

## 3.2 约束说明

- 仅支持在创建gms_xmlparser插件后使用
- 仅支持parse,newparser,freebuffer,parserclob,parserbuffer,getdocument相关函数接口
