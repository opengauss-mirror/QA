# 1 概述

本特性是opengauss数据库中，全模式下的with ordinality语法的支持，with ordinality用于为集合返回函数（Set-Returning Functions, SRFs）的结果自动生成行序号 ，当 from语句后面的函数加上 WITH ORDINALITY 属性后, 那么返回的结果集将在后面增加一个整数列, 这个整数列从1开始, 并且按 1 递增。
