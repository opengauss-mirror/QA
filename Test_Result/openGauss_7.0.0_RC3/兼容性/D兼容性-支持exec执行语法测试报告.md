**Keywords 关键词**：exec语法；存储过程；函数；D兼容模式；功能测试；兼容性测试

**Abstract 摘要**：

本针对《支持sqlserver exec执行语法》需求进行了全面的测试验证。测试范围涵盖exec语法在D兼容模式下执行标量函数、存储过程的基本功能，包括不同参数类型（整型、浮点、字符串、日期等）、异常场景、事务与嵌套调用、集群运维场景等。共执行37个测试用例，结果显示exec语法在D兼容模式下功能正常，能够正确调用存储过程和函数，返回值符合预期，异常报错合理。其中发现向主键字段插入NULL未报错的问题，已作为问题单提交。整体测试结果表明，该需求基本满足设计要求，具备较好的兼容性和稳定性。
