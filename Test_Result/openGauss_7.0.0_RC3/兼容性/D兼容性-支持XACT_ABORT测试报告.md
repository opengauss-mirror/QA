# 1 概述

测试支持D模式下SET XACT_ABORT ON/OFF语法：

1.基本功能测试，不影响原有的sql情况，参数设置为off时，仅回滚执行错误的事务；参数设置为on，回滚执行的所有事务

2.常用场景的交互测试（包含存储过程、嵌套事务、try...catch交互、死锁场景、并发场景等）

3.兼容性场景测试
