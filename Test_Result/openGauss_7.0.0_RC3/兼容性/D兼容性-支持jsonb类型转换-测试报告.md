# 1 概述

  支持将使用jsonb操作符'->'查询出的结果（jsonb）转换为其他类型，支持范围如下：

| 整数类型 | 浮点数类型 | 布尔类型 | 日期时间类型 |
| -------- | ---------- | -------- | ------------ |
| int1     | numeric    | bool     | date         |
| int2     | float4     |          | time         |
| int4     | float8     |          | timestamp    |
| int8     |            |          |              |

​        本报告描述[支持jsonb类型转换为 bool类型、 数值类、时间类](https://gitcode.com/opengauss/openGauss-server/issues/7779)特性测试活动，本需求随openGauss 7.0.0-RC3.B018版本发布，在openGauss 7.0.0-RC3.B018版本上进行测试验证。
