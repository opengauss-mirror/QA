# 3 版本概要测试结论、关键风险和规避措施

## 3.1 测试结论总结

D库系统函数特性测试，共计执行了102个用例，主要覆盖了功能测试、升级测试、兼容性测试、耦合功能测试、资料测试。

功能测试覆盖了Object相关函数object_name获取object的名称、obejct_schema_name获取object的schema的名称、object_definition获取object的定义、objectpropertyex获取object的属性，列相关函数col_length获取列的长度、col_name获取列的名称、columnproperty列的属性，日期相关函数year获取date中的年份、month获取date中的月份、day获取date中的天、isdate判断是不是合法的date、eomonth获取月的最后一天、sysdatetime获取当前时间，字符串相关函数patindex获取第一个匹配默认的下标、stuff字符串的删除和替换、str浮点类型转成字符串、replicate字符串的复制、string_split字符串的分割、quotename字符串的包裹、trim字符串去除首末空格，sql_variant相关函数sql_variant_property获取sql_variant的基本功能，异常使用，权限限制等。

升级测试主要覆盖从不带shark插件的RC1版本->shark插件3.0的RC3版本，带shark插件1.0的RC1版本->shark插件3.0的RC3版本，带shark插件2.0的RC2版本->shark插件3.0的RC3版本3个场景进行升级中执行相关业务，回滚中执行相关业务，测试升级和回滚过程正常无报错。

兼容性测试主要针对其他兼容性库进行该特性验证，覆盖A,B,C,PG兼容性，相关不支持语法正确报错，数据库功能正常，无core无宕机。

耦合功能测试包含数据库相关工具功能验证，使用JDBC、ODBC、PDBC执行本特性相关语法，功能与gsql一致，无其他功能问题

资料测试针对官网资料进行测试，相关描述正确无歧义，约束准确，示例可执行。

测试中发现8个问题，7个功能问题，1个资料问题，其中涉及本需求的问题6个，相关问题单正在修改中，整体质量良好。

## 3.2 约束说明

- 在D库中加载shark插件使用
- 部分函数入参只支持可以隐式转换成入参支持的数据类型

## 3.3 关键风险和规避措施

无
