# 1 概述

 使用场景：

1）用户使用ALTER TABLE语句向表中增加列时，期望通过IF NOT EXISTS语句增加健壮性。

2）用户使用脚本执行ALTER TABLE语句向表中增加列时，期望通过IF NOT EXISTS语句避免抛出错误中断脚本运行。

​        本报告描述[支持ALTER TABLE ADD COLUMN [IF NOT EXISTS]语法](https://gitcode.com/opengauss/openGauss-server/issues/7780)特性测试活动，本需求随openGauss 7.0.0-RC3.B018版本发布，在openGauss 7.0.0-RC3.B018版本上进行测试验证。
