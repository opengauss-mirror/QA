# 1 概述

本特性主要实现D库系统视图兼容，用于提升D库系统视图兼容性。

DATABASE_PRINCIPALS 返回数据库角色相关的信息。

FOREIGN_KEY_COLUMNS 返回外键约束相关的信息。

FOREIGN_KEYS 返回外键约束相关的信息。

SYSFOREIGNKEYS 返回外键约束相关的信息。

KEY_CONSTRAINTS 返回主键和唯一约束相关的信息。

CHECK_CONSTRAINTS 返回CHECK约束相关的信息。

INDEX_COLUMNS 返回索引相关的信息。

SYSPROCESSES 返回数据库会话相关的信息。

SYNONYMS 返回同义词相关的信息。

SYSTEM_OBJECTS 返回系统对象的信息，D库中将information_schema、pg_catalog、sys、information_schema_tsql共四个模式作为系统模式，该视图返回系统模式对象以及dbe_perf模式的视图信息。

ALL_VIEWS 返回所有系统视图和用户视图相关的信息。

SEQUENCES 返回序列相关的信息。

TRIGGERS 返回DDL和DML触发器相关的信息。

TRIGGER_EVENTS 返回DDL和DML触发器相关的信息。

CONFIGURATIONS 返回参数相关的信息。

SYSCURCONFIGS 返回参数相关的信息。

SYSCONFIGURES 返回参数相关的信息。
