# 3 版本概要测试结论、关键风险和规避措施

## 3.1 测试结论总结

openGauss支持二进制代码段大页特性, 共计执行了14个用例, 主要覆盖了功能测试, 性能测试, 升降级测试, CI测试, 资料测试

功能测试主要涉及OM安装能否按预期开启二进制代码段大页以及二进制代码段大页是否生效. 主要测试点如下: 1. 确认代码段大页生效即二进制代码段按照2M对齐. 2. xml配置文件中开启enableHugeBin, 出现app\_\<commit\>\_huge目录并且自动挂载到tmpfs下. 3. 服务器重启后目录自动挂载. 4. 扩容自动配置大页二进制, 自动挂载tmpfs, 用户无感知. 5. 升级自动配置大页二进制, 自动挂载tmpfs, 用户无感知.

升级测试主要覆盖7.0.0RC2->7.0.0RC3, 6.0.0->7.0.0RC3两个场景, 分别执行升级, 回滚, 回滚后升级, 升级提交业务, 并且在升级提交后验证相关功能, 升级流程以及相关功能正常无报错. 

性能测试主要针对需求中提出的性能场景进行验证, 使用920 2P机型, 内存500GB, OS为openEuler24.03, OS PAGESIZE为4K的环境进行验证. 开启二进制代码段大页相比不开启的情况下TPC-C测试性能表现提升2%.

CI测试主要涉及YAT测试用例中SQL目录和TOOLS目录, 选择SQL/DDL, SQL/DCL, SQL/DML, SQL/DQL, TOOLS/COMPILATION, TOOLS/SERVER_TOOLS, TOOLS/INTERNAL_TOOLS, TOOLS/OPEN_TOOLS测试套进行连跑, 未出现相关问题

资料测试针对官网资料进行测试，相关描述正确无歧义，约束准确，示例可执行。

测试中发现2两个问题, 总DI为0.2, 代码量0.5k, 缺陷密度0.4, 相关问题单正在修改中, 整体质量良好. 

## 3.2 约束说明

1. xml文件中添加`<PARAM name="enableHugeBin" value="on"/>`
2. root用户下执行预安装
