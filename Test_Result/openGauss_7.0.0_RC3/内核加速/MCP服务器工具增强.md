| ------ | -------------------------- | ------------------------------------------------------------ |
| LLM    | Large Language Model | 大语言模型：就像 ChatGPT 这样的 AI 模型，拥有强大的语言理解和生成能力，但它们的知识局限于训练数据，且可能产生“幻觉” |
| MCP   | Model Context Protocol | 是一个新兴的开放协议，通过标准化的方式将外部数据源和工具连接到LLM应用中。其核心价值在于为数据库与LLM的协同提供了统一、安全且高效的桥梁 |

# 1 概述

通过增加功能增强MCP服务的能力，新增向量检索、混合查询等高级功能，openGauss MCP大幅增强了数据库与LLM的协同能力，使两者在复杂数据交互中配合更紧密、效果更精准，为用户提供更高效、更便捷的数据库与LLM协同体验。

## 3.1 测试结论总结

本次测试分别搭建openGauss底座数据库、openGauss MCP服务。客户端选用vscode插件cline使用deepseek模型协议使用openGauss MCP服务。覆盖了跨节点交互使用、向量检索、混合查询等场景，验证了MCP服务在openGauss底座数据库上使用。所有接口单元测试通过，个别交互场景存在异常，提单2个缺陷，整体测试通过，质量良好。
