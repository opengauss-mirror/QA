# 3 版本概要测试结论、关键风险和规避措施

## 3.1 测试结论总结

openGauss异步直接IO特性, 共计执行了43个用例, 主要覆盖了功能测试, 升级测试, 性能测试, 文档测试.

功能测试涵盖了三个主要功能, 非段页式表支持直接IO, PageWritter刷盘线程以及Vacuum Full刷盘支持异步IO写, Astore行存表顺序扫描支持异步IO读, 以及GUC参数测试. 针对非段页式表支持直接IO功能, 通过对段页式表, astore表, ustore表, 非日志表, 分区表, 临时表等进行测试. 对PageWriter线程刷盘以及Vacuum Full刷盘支持异步IO写功能, 分别在执行写入场景以及执行Vacuum Full table_name场景下进行验证. 针对Astore行存表顺序扫描(SeqScan)支持异步IO读(预读)功能, 通过对astore表进行顺序扫描查询进行验证. 

升级测试主要覆盖7.0.0RC1版本->7.0.0RC3版本以及6.0.2版本->7.0.0RC3版本两个场景, 分别执行升级, 回滚, 回滚后升级, 升级提交业务, 并且在升级提交后测试相关功能, 升级流程以及相关功能正常无报错. 

性能测试针对需求中提出的性能场景进行验证, 满足8核32GB, SSD硬盘(IO吞吐量250MB/s, 与机械硬盘接近). 基于sysbench验证, 150G数据, 数据库参数设置 shared_buffers开启adio 20G, 关闭8GB, 使用直接异步IO, 只读场景下性能持平, 只写场景下提升10%的要求

资料测试针对官网资料进行测试，相关描述正确无歧义，约束准确，示例可执行。

测试中发现4个问题, 总DI为5.1, 代码量1.7K, 缺陷密度3, 相关问题单正在修改中, 整体质量良好
