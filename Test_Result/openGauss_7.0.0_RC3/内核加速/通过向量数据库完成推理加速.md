# 1 概述

根据Cacheblend框架，实现在不同请求之间，智能服务、合并KV Cache，以减少重复计算。Cacheblend使用需要搭配Dify、vllm（LLM启动框架）和Lmacache（KV Cache存储与检索引擎）；本次测试旨在验证通过这套框架搭建服务，Dify层语料库落盘到openGauss数据库，KV Cache层缓存计算信息也同样入库到openGauss，搭建完成后验证基本功能即可。
