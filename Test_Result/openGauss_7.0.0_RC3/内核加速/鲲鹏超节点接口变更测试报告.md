# 3 版本概要测试结论、关键风险和规避措施

## 3.1 测试结论总结

本测试完成功能测试、性能测试、可靠性测试，测试详情如下：

功能测试：测试变更接口名字，测试SMB工具和failover是否能正确执行。

性能测试：failover -f是否能瞬间执行。

用例共10个，共计1轮。

期间发现：

（1）SMB工具需要重命名两个.so文件，否则会段错误报core信息。

（2）主机没有kill的期间备机执行failover，会出现无事发生，备机升主，主备节点均down的情况。

与开发确认为必要流程，非质量问题。

整体质量良好无明显漏洞。

## 3.2 约束说明

SMB工具需要重命名，令其找环境中的.so文件

主机需要手动kill备机才能执行failover，否则会出现意料之外的情况。

## 3.3 关键风险和规避措施

无
