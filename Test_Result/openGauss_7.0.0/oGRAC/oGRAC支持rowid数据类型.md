# 1 概述

  本次测试旨在全面验证数据库对ROWID数据类型的支持情况，包括ROWID列的创建与管理（DDL操作）、
ROWID相关系统函数（ROWIDTOCHAR、ROWIDTONCHAR、CHARTOROWID）的正确性、ROWID与字符串等
数据类型之间的隐式转换、ROWID列上唯一索引和复合索引的创建与使用、DML操作中ROWID的处理、
事务提交与回滚、存储过程和触发器中ROWID的使用、边界值与异常场景的处理，以及各类函数之间的 
耦合一致性。

# 3 版本概要测试结论、关键风险和规避措施

## 3.1 测试结论总结

本次测试oGRAC支持rowid数据类型特性，共计10个用例，主要包含rowid的基础功能测试以及资料测试。

ROWID数据类型的支持情况，包括ROWID列的创建与管理（DDL操作）、ROWID相关系统函数（ROWIDTOCHAR、
ROWIDTONCHAR、CHARTOROWID）的正确性、ROWID与字符串等数据类型之间的隐式转换、ROWID列上唯一索引
和复合索引的创建与使用、DML操作中ROWID的处理、事务提交与回滚、存储过程和触发器中ROWID的使用、边
界值与异常场景的处理，以及各类函数之间的 耦合一致性。

资料测试针对官网关于oGRAC下rowid数据类型描述，相关描述无歧义。

测试中共发现1个问题，整体质量良好。
