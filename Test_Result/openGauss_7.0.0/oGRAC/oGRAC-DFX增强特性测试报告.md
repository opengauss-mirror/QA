# 1 概述

本报告主要覆盖新增系统视图：dv_dss_time_stats，支持采集DSS设备操作统计信息采集；dv_sql_excution_plan、dv_drc_buf_info、dv_drc_local_lock_info、dv_buf_ctrl_info四个内存页面、SQL执行计划等视图新增字段；dv_slow_sql系统慢SQL信息采集新增字段，测试字段采集信息是否准确。
