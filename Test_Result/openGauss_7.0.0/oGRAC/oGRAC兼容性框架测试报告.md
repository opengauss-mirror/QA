**Keywords 关键词**：oGRAC兼容性框架

**Abstract 摘要**：本报告是对oGRAC兼容性框架特性的测试总结，该特性旨在oGRAC中增加A/B/C库兼容性框架，支持创建A/B/C兼容性数据库，然后不同的兼容性数据库支持不同的parse、系统函数、操作符、系统视图、系统表和转换类型规则分支，以实现不同兼容性下语法独立开发和解耦。

# 3 版本概要测试结论、关键风险和规避措施

## 3.1 测试结论总结

oGRAC兼容性框架特性，共执行了9个用例，主要覆盖了功能测试、资料测试。

功能测试主要覆盖在oGRAC中创建A/B/C兼容性数据库，验证不同兼容性数据库对解析器、系统函数、操作符、系统视图、系统表及类型转换规则等分支的支持能力，保障不同兼容模式下语法逻辑的独立开发与解耦。各测试场景均配套对应SQL示例。

资料测试针对官网资料进行测试，相关描述正确无歧义，约束准确，示例可执行。

测试中发现1个功能问题，相关问题单正在修改中，整体质量良好。

## 3.2 约束说明

parse语法解析和操作符兼容时需要开启USE_BISON_PARSER
