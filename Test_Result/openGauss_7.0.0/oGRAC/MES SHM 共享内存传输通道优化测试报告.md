# 3 版本概要测试结论、关键风险和规避措施

## 3.1 测试结论总结

本轮针对 MES SHM 共享内存传输通道特性保留 37 条有效测试用例并完成执行，覆盖 GUC 参数、兼容性、CPU 绑核、DMS 参数透传、动态库加载、共享内存对象创建、对端映射、ub_comm_queue 初始化、连接 ready、消息发送、回调投递、心跳、清理释放、统计日志、故障注入和 walreceiver 参数同步等场景。

测试中共发现2个问题，功能基本正常，整体质量良好。


## 3.2 约束说明

- SHM 模式仅在 ss_interconnect_type 配置为 SHM 时启用。
- SHM 模式依赖灵衢超节点的 UBS Memory 服务和 ub_dist_comm_queue 库。
- SHM 模式下不启动 MES 接收线程 mes_start_receivers，消息接收由 ub_dist_comm_queue 回调驱动。
- ss_shm_ub_comm_cpu_bind 参数仅在 SHM 模式下生效，格式为 [id,id,...] 或 [lo~hi]，9 个槽位对应 9 个队列

## 4.3 产品质量属性目标(DFX)测试结论

###  4.2.1 性能测试结论

| 场景      | 参数                         | 主机 tpmC    | 备机 tpmTOTAL | 总性能 = 主机 tpmC + 备机 tpmTOTAL | 相比基线 |
| :-------- | :--------------------------- | :----------- | :------------ | :--------------------------------- | :------- |
| 300 + 300 | 基线 TCP / enable_ub=off     | 1,112,072.59 | 2,538,856.75  | 3,650,929.34                       | -        |
| 300 + 300 | 优化 SHM / enable_ub=on      | 763,643.14   | 3,407,160.65  | 4,170,803.79                       | +14.24%  |
| 500 + 100 | 基线 TCP / enable_ub=off     | 1,209,659.41 | 2,617,371.89  | 3,827,031.30                       | -        |
| 500 + 100 | 优化 SHM / enable_ub=on      | 989,224.69   | 3,619,876.21  | 4,609,100.90                       | +20.43%  |

300 + 300 场景明细：

| 指标          | 基线         | 优化后       | 变化    |
| :------------ | :----------- | :----------- | :------ |
| 主机 tpmC     | 1,112,072.59 | 763,643.14   | -31.33% |
| 主机 tpmTOTAL | 2,471,888.91 | 1,697,762.16 | -31.32% |
| 备机 tpmTOTAL | 2,538,856.75 | 3,407,160.65 | +34.20% |
| 合计 tpmTOTAL | 5,010,745.66 | 5,104,922.81 | +1.88%  |
| 合计事务数    | 100,217,861  | 102,100,836  | +1.88%  |

500 + 100 场景明细：

| 指标          | 基线         | 优化后       | 变化    |
| :------------ | :----------- | :----------- | :------ |
| 主机 tpmC     | 1,209,659.41 | 989,224.69   | -18.22% |
| 主机 tpmTOTAL | 2,688,435.85 | 2,198,644.26 | -18.22% |
| 备机 tpmTOTAL | 2,617,371.89 | 3,619,876.21 | +38.30% |
| 合计 tpmTOTAL | 5,305,807.74 | 5,818,520.47 | +9.66%  |
| 合计事务数    | 106,120,558  | 116,374,649  | +9.66%  |

性能测试结论：

- 300 + 300 场景下，优化 SHM / enable_ub=on 相比基线 TCP / enable_ub=off，总性能由 3,650,929.34 提升至 4,170,803.79，提升 14.24%；备机 tpmTOTAL 提升 34.20%，合计 tpmTOTAL 和合计事务数均提升 1.88%。

- 500 + 100 场景下，优化 SHM / enable_ub=on 相比基线 TCP / enable_ub=off，总性能由 3,827,031.30 提升至 4,609,100.90，提升 20.43%；备机 tpmTOTAL 提升 38.30%，合计 tpmTOTAL 和合计事务数均提升 9.66%。

- 开启 SHM 优化后，主机 tpmC 和主机 tpmTOTAL 有所下降，虽备机 tpmTOTAL 明显提升，但整体未达到验收指标，性能测试结论为未通过。

  https://gitcode.com/opengauss/openGauss-server/issues/8209
