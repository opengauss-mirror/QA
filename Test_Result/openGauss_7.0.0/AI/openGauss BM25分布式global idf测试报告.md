# 3 版本概要测试结论、关键风险和规避措施

## 3.1 测试结论总结

本报告主要对以下几个功能点进行功能测试，参数enable_bm25_global_idf正常和异常设置验证，参数bm25_global_stat功能验证，函数bm25_table_stat(text,text[,text,text]);验证，多个BM25索引查询参数结合功能验证

性能测试，1CN、2DN环境下，Multi-CPR医疗子集（96万）复制扩展到5000万，8并发查询，相比非分布式场景性能劣化10%以内，召回率对比单机劣化2%以内

资料测试针对官网资料进行测试，文档描述准确清晰。

测试中发现2个功能问题。整体质量良好。
