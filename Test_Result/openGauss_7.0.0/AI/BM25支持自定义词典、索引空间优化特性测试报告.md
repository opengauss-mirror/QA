# 3 版本概要测试结论、关键风险和规避措施

## 3.1 测试结论总结

BM25支持自定义词典、索引空间优化特性，共计执行用例25个，主要覆盖功能测试、性能测试、升级测试、稳定性测试、资料测试。

功能测试主要覆盖自定义词典dict_path合法和不合法路径测试，自定义词典完整性、文件权限测试，自定义词典与历史版本兼容性测试。同时覆盖了索引空间优化下的基于BM25索引的增删改查测试，相同数据量下的索引空间占用测试

升级测试主要覆盖从不带该特性版本升级到该特性版本，在升级前、中、后执行BM25索引创建、使用，同时在回滚中执行相关业务，测试升级和回滚过程正常无报错

性能测试主要对BM25索引空间优化特性，在测试脚本下对Multi-CPR: 大规模段落检索多领域中文数据集使用BM25索引的QPS，平均时延和索引空间占用进行测试，空间占用优化59.48%，大于特性测试验收目标40%。

稳定性测试主要针对性能测试下，数据库状态和内存检测。数据库状态正常，内存检测正常。

资料测试针对官网资料进行测试，相关描述正确无歧义，约束准确，示例可执行。

测试中发现4个问题。2个资料问题，2个功能问题，整体质量良好。

## 3.2 约束说明

- dict_path仅支持绝对路径；空/未指定表示默认词典
- 词典目录必须满足固定文件名集合（仅目录可配置，不支持逐文件自定义），（jieba.dict_utf8,hmm_model.utf8,user.dict.utf8,idf.utf8,stop_words.utf8）
- 缓存key使用realpath解析后的路径，避免符号链接与路径变体造成重复加载
- 多线程并发，缓存创建过程中加锁，保证同一key不会并发创建多份实例
- 自定义词典的特性约束，更新词典后会导致已有的index失效，不允许alter dict_path配置
