# 1 概述
针对to_char(numeric fmt)函数的执行性能进行深度优化，在兼容原有语法和输出语义的前提下，新增两种高频千分位格式（999,999.99, 999,999,999.99）的硬编码快速转换路径，提升执行效率，降低表达实质性的CPU占用与内存分配开销。

# 3 版本概要测试结论、关键风险和规避措施

## 3.1 测试结论总结
宽表null列占比高场景更新性能优化测试，共执行了11个用例，主要覆盖了功能验证，兼容性测试、性能测试三个方面，需求100%实现。，整体质量良好。

功能测试主要覆盖两种高频千分位格式（999,999.99, 999,999,999.99）的to_char函数使用场景，包括基本功能验证、显式隐式、非目标重载不受影响、DML语句中使用、behavior_compat_options开关功能验证、其他to_char函数正常使用验证等场景。

性能测试包括to_char(mueric, format) 函数场景，当format为 "999,999.99" 和 "999,999,999.99" 格式时，性能提升35%，其他to_char使用场景可以正常操作性能无劣化。

兼容性测试包括对opengauss数据库B兼容性测试，以及企业版轻量版数据库测试。
