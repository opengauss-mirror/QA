# 3 版本概要测试结论、关键风险和规避措施

## 3.1 测试结论总结

传统主备性能优化-cache-miss优化特性共计执行26个用例，主要覆盖功能测试、性能测试、可靠性测试、升级测试和资料测试。功能测试验证4个优化项新增功能和不影响继承功能，如视图新增store和hit次数监控测试；性能测试覆盖定向性能验证，优化后平均QPS提升5% ；升级测试验证openGauss 7.0.0RC3升级至7.0.0LTS版本后视图功能验证及回退成功；可靠性验证覆盖swichover\failover\关键worker故障恢复，数据库集群状态正常 ；资料测试覆盖该需求相关资料验证。用例执行率100%，发现2个有效问题，整体质量良好。

## 3.2 约束说明

1、track_activities=off 只关闭统计观测，不关闭 rowdesc 缓存功能。
2、shared GPC plan 场景禁止继续使用共享 row_desc_buf 作为 rowdesc 宿主。

## 3.3 关键风险和规避措施

无
