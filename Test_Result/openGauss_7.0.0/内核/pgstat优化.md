# 1 概述

本次测试围绕 openGauss 数据库统计信息收集功能展开，涵盖 24 个测试用例，涉及 pg_stat_* 系列视图的功能验证、准确性验证、一致性验证、稳定性验证及资源占有率优化验证。
测试范围包括：表级统计、索引统计、数据库级统计、函数统计、活动会话统计、复制统计、IO 统计、冲突统计、后台写入统计、坏块统计，以及临时表、分区表、事务内统计、主备一致性、重启/升级前后数据一致性、资源占用优化等场景。

# 3 版本概要测试结论、关键风险和规避措施

## 3.1 测试结论总结


本次测试针对pgstat优化特性，围绕pg_stat_* 系列视图的功能验证、准确性验证、一致性验证、稳定性验证，升级校验及资源占有率优化验证。
具体包含各类pg_stat_*统计视图的表级统计、索引统计、数据库级统计、函数统计、活动会话统计、复制统计、IO 统计、冲突统计、后台写入统计、坏块统计，以及临时表、分区表、事务内统计、主备一致性的验证。
升级前后数据一致性验证，长时间sysbench下，CPU、IO、内存占用率优化的测试。
测试中发现1个问题，整体质量良好。
