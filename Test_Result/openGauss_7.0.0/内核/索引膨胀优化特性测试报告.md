# 3 版本概要测试结论、关键风险和规避措施

## 3.1 测试结论总结

索引膨胀优化特性测试，共计执行用例6个，主要覆盖功能测试、性能测试、资料测试。

功能测试主要覆盖创建btree索引指定分裂策略为insertpt路径、btree索引分裂策略为default、原有的ubtree的功能测试和ubtreepcr的功能测试


性能测试主要对btree索引指定分裂策略为insertpt路径，开启去重参数enable_default_index_deduplication=on下，数据库data分盘后的IO速率下降约4.52倍，大于特性测试验收目标IO速率下降4倍。


资料测试针对官网资料进行测试，未新增btree索引指定分裂策略相关说明，已提资料单。

测试中发现1个问题。为资料问题，整体质量良好。

## 3.2 约束说明

- 仅当页空间不足触发分裂时进入该路径；普通插入路径不变。
