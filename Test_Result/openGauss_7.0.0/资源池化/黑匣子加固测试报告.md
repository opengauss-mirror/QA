# 1 概述

本报告针对数据保险柜加固点进行功能测试，覆盖了CM-Rest API新增3个资源监控相关接口，内存监控、CPU监控、磁盘IO监控；oGRecorder优化gr_vfs_query_file_info接口；
主要验证功能是否正常，异常场景执行是否符合预期，并发调用（多线程）是否正常等。输出测试用例26个，整体质量良好。
