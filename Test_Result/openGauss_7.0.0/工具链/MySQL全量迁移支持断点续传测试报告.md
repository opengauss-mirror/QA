# 3 版本概要测试结论、关键风险和规避措施

## 3.1 测试结论总结

MySQL全量迁移支持断点续传特性测试，共计执行用例30个，主要覆盖功能测试、性能测试、前向兼容性测试、资料测试。

功能测试主要覆盖MySQL全量迁移从源端数据库到迁移工具到目标数据库中各阶段中断场景下，进入续传阶段数据完整性、准确性的功能测试

前向兼容性测试主要对datakit已有功能进行覆盖测试，不影响其他功能的正常使用


性能测试主要对MySQL全量迁移在10张表，每张表1000w条数据（无主键无索引）下，调整迁移时的读写线程数为20，迁移速率为358.36MB/S，大于特性测试验收目标300MB/S。

资料测试针对官网资料进行测试，文档描述准确清晰。

测试中发现5个问题。本需求内问题2个，整体质量一般。

## 3.2 约束说明

- 只在迁移失败情况下可用断点续传功能，手动结束迁移任务之后不可进行断点续传

## 3.3 关键风险和规避措施
