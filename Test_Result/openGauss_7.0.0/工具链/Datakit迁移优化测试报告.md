# 1 概述

本报告针对1.MySQL全量迁移中，数据库对象迁移时同名用户进行测试，覆盖函数、存储过程、视图、触发器场景，验证目标库迁移后同名用户创建情况。2.在datakit迁移流程中，对前台页面显示、后台数据库数据进行测试。3.支持Datakit卸载时通过选项同步卸载prometheus、portal等组件，正常和异常场景下的卸载功能测试。测试对象为合入该特性的转测版本，版本为openGauss-Datakit-All-7.0.0-RC3.tar.gz，主要从功能测试，前向兼容性测试，资料测试等进行验证。

# 3 版本概要测试结论、关键风险和规避措施

## 3.1 测试结论总结

本报告主要对以下几个功能点进行功能测试，1.MySQL全量迁移中，数据库对象迁移时同名用户进行测试，覆盖函数、存储过程、视图、触发器场景，验证目标库迁移后同名用户创建情况。2.在Datakit迁移流程中，涉及迁移模式、迁移对象选项，对前台页面显示、后台数据库数据进行测试。3.支持Datakit卸载时通过选项同步卸载prometheus、portal等组件，正常和异常场景下的卸载功能测试。

前向兼容性测试主要对Datakit历史迁移任务、后台字段及功能进行测试

资料测试针对官网资料进行测试，文档描述准确清晰。

测试中发现1个问题，非本需求内问题。整体质量良好。
