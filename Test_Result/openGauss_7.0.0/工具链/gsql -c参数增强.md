# 3 版本概要测试结论、关键风险和规避措施

## 3.1 测试结论总结
gsql -c参数增强测试，共执行了112个用例，主要覆盖了功能验证，可靠性测试，资料测试、兼容性测试、性能测试五个方面，需求100%实现。，整体质量良好。

功能测试主要覆盖gsql相关参数，包括多个-c参数、-c与-f组合、-c与-1组合、-c与-l组合、-c与ON_ERROR_STOP、异常场景组合等类型， 涵盖基本gsql参数类型。

性能测试包括并发执行场景，可以正常操作。

兼容性测试包括对opengauss数据库兼容性测试，以及企业版轻量版数据库测试。

可靠性测试包括100条大数据测试、多次迁移测试，数据库异常中断等场景。

资料测试 相关文档更新在官网gsql页面。
