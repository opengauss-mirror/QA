# 1 概述

本报告主要覆盖在gsql中支持使用元命令 `\gset [prefix]` 执行当前查询缓冲区中的SQL，并将返回的单行结果按"列名（可选前缀+列名）"映射为当前会话变量。
测试目标：验证 `\gset` 元命令在A库、B库、PG库、D库下的功能正确性、约束正确性、异常处理的健壮性，以及与gsql已有特殊控制变量、FETCH_COUNT、游标等机制交互时的兼容性。
