# 3 版本概要测试结论、关键风险和规避措施

## 3.1 测试结论总结
openGauss SQLServer兼容性下支持SQL_VARIANT数据类型。共计执行41个用例，主要覆盖创建不同类型的表使用SQL_VARIANT类型，对表插入正常、异常值测试，对SQL_VARIANT类型进行显式类型转换和隐式类型转换测试，以验证数据类型的正常使用。结合操作符、列、参数、变量和函数返回值等常见测试场景对SQL_VARIANT类型进行功能测试，以及在升级场景验证SQL_VARIANT类型能否正常使用，并对特性文档内容进行验证。通过手工执行用例，升级测试、文档测试验证通过，基础功能测试发现问题1个，目前待处理状态，整体质量良好。

## 3.2 约束说明

1.该功能在openGauss的D兼容模式下使用，需建立shark插件使用。
