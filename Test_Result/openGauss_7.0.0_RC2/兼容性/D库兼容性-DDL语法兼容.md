**Keywords 关键词**：D兼容性语法；DDL；proc；CONSTRAINT WITH；ON/TEXTIMAGE_ON

**Abstract 摘要**：本报告是对新增特性——D库兼容性-DDL语法兼容性进行测试总结，该特性旨在对D库DDL相关语法兼容，包括：支持通过create proc 方式创建存储过程，功能和procedure方式一致；支持通过alter proc 方式修改存储过程，功能和procedure 方式保持一致；支持通过drop proc 方式删除存储过程，功能和procedure 方式保持一致；兼容USE语法，仅支持USE当前连接的数据库，不支持连接到其他数据库；建表语句支持ON {filegroup | "default" }选项，无实际作用；建表语句中的constraint语法支持ON {filegroup | "default" }选项；建表语句中的constraint语法支持TEXTIMAGE_ON {filegroup | "default" }选项；建表语句支持创建的constraint通过with给出选项，仅语法支持。通过在目标环境中测试，该特性表现符合预期，整体测试质量优秀。

# 1 概述

本报告主要测试D库兼容性-DDL语法兼容性包括create proc、alter proc、drop proc、USE等功能性支持以及仅语法支持的constraint语法支持ON、constraint语法支持TEXTIMAGE_ON、建表语句支持ON {filegroup | "default" }和建表语句支持创建的constraint通过with给出选项。

# 3 版本概要测试结论、关键风险和规避措施

## 3.1 测试结论总结

本报告主要测试D兼容性8个特性，共计执行测试用例72个，主要覆盖了功能测试、兼容性测试、驱动测试、升级测试、资料测试等。升级测试在7.0.0-RC1版本升级到7.0.0-RC2版本后执行用例验证此功能的正确性；兼容性测试覆盖在不同兼容模式验证该功能；驱动测试覆盖使用jdbc驱动和psycopg2驱动。测试输出用例72个，资料暂未合入，以问题单跟踪，整体测试质量优秀。

## 3.2 约束说明
 - Alter proc/procdure COMPILE 仅在A库中生效，D库报错不支持；
 - 仅支持USE当前数据库，不支持连接到其他数据库，若USE数据库名不是当前数据库则报错；
 - 建表语句支持创建的constraint通过with给出选项同A库和原生D库index_parameters选项范围类似，仅FILLFACTOR设置1~10均默认为10，仅D库UNIQUE和PARAIMARY KEY 约束支持新增的参数
 - 约束中的on filegroup 子句仅在primary key 和unique约束中生效；
 - 原生的ON COMMIT OPTION和ON TEXTIMAGE_ON/ON filegroup 无法并存
