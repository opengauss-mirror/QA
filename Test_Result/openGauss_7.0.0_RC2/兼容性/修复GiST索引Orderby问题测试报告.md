# 1 概述

​        本需求：

1. 修复 GiST lossy场景，索引扫描存在 order by expr 表达式时， 排序结果错误的问题
2. 增加 circle 类型 GiST 索引场景支持 Order by expr

​        本报告描述[gist索引有损存储场景(geometry 类型)支持order by expr](https://gitcode.com/opengauss/org-issue/issues/66 )特性测试活动，本需求随openGauss 7.0.0-RC2 （B019）版本发布，在openGauss 7.0.0-RC2 （B020）版本上验证。
