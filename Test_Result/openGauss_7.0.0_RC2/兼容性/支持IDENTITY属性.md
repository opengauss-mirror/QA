**Abstract 摘要**：本文档是对openGauss D兼容性下支持IDENTITY属性的测试。

1.实现D兼容模式下，CREATE/ALTER TABLE时支持给指定字段赋予IDENTITY属性，用于获得自动增加的标识号。

2.测试CREATE/ALTER TABLE时指定字段赋予IDENTITY属性、插入数据让IDENTITY标识列的字段值是自动生成、导入导出等场景。

# 1 概述

该测试需求的目的是增强openGauss的D兼容性，实现支持CREATE/ALTER TABLE时指定字段赋予IDENTITY属性，且插入数据时IDENTITY标识列的字段值是自动生成的。

# 3 版本概要测试结论、关键风险和规避措施

## 3.1 测试结论总结

openGauss的D兼容模式下，实现支持CREATE/ALTER TABLE时指定字段赋予IDENTITY属性，且插入数据时IDENTITY标识列的字段值是自动生成的。共计执行18个用例，主要覆盖创建表、修改表等语法，对含IDENTITY属性的表进行DML操作，还测试了权限、导入导出等关联场景。结合常用测试场景，通过手工执行用例，发现问题3个，整体质量良好。

## 3.2 约束说明

1.该功能在openGauss的D兼容模式下使用。
