# 1   概述

此特性主要是openGauss数据库在D模式库中兼容SQL server数据库@object声明变量语法，以便于用户使用该功能。具体使用是在D兼容模式函数和存储过程中，参数的命名规则允许使用@作为开头命名。其次还增加了设置d_format_behavior_compat_options = 'enable_abs'，select @列名获取到的未该列的绝对值。

# 3   版本概要测试结论

 openGauss 7.0.0-RC2.B024版本测试阶段完成了基本功能测试、兼容性测试、特性耦合测试以及资料测试，不涉及性能测试。未发现问题，无遗留风险，整体质量良好。

openGauss数据库 D模式下支持@object声明变量功能 ，共计执行了46个用例，主要覆盖了基本功能测试、兼容性测试、异常测试、耦合性测试以及资料测试。功能测试覆盖了多个基本测试点，包含@声明变量名为关键字、数字、空格、中文、特殊字符（仅支持\#  $）以及空值；@变量赋值为直接赋值、表达式赋值；@变量作用域为局部变量和子嵌套作用域；@变量在匿名块、动态语句、查询子句中使用；异常测试包含定义值与赋值不符合等；兼容性测试是在数据库多种兼容模式下执行；特性耦合测试包含导入导出等测试项。测试中未发现问题，无遗留问题整体质量良好。
