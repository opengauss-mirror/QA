**Keywords 关键词**：D库

**Abstract 摘要**：实现D库常用语法的一部分函数兼容，本特性包括：第一，支持ISNULL函数；第二，支持ATN2函数；第三，支持LOG10函数；第四，支持DATEDIFF和DATEDIFF_BIG函数；第五，支持CHARINDEX函数；第六，支持CAST和TRY_CAST函数；第七，支持CONVERT和TRY_CONVERT函数。

# 3 版本概要测试结论、关键风险和规避措施

## 3.1 测试结论总结

D库常用函数兼容测试，共执行16个用例，主要覆盖了功能测试、兼容性测试、升级测试、备份测试、资料测试。函数基本功能测试，函数单独使用及使用存储过程或自定义函数调用等测试。兼容性测试，在不同兼容性数据库执行函数。升级测试，验证升级后在提交与未提交时以及回滚后，测试函数功能是否支持且结果准确无误。备份测试，验证执行函数后是否可以使用gs_dump和gs_restore正常进行备份数据与恢复数据库。资料测试，验证资料描述是否准确无误、约束是否体现、示例执行结果是否符合预期、资料是否完备。测试中发现个问题，整体质量良好。
