# 1 概述

本特性通过增加一种新的checkpoint类型，即将页面向一块逻辑上非易失性的共享内存做checkpoint来进一步降低RTO时间。因为是纯内存操作，新增checkpoint类型会比传统向磁盘写的checkpoint类型快很多，从而通过两种checkpoint协同工作减少恢复时需要回放的redo日志量，进一步降低RTO。
