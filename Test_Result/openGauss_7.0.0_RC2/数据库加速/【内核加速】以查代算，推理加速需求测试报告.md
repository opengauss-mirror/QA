# 1 概述

本需求将vllm-ascend和 自研的 openGauss 加速库相结合，实现KV Cache 以查代算推理加速。本报告主要测试Deep-Distill-Qwen-32B模型，128k长序列推理HBM资源的占用下降以及端到端吞吐量的提升，测试主要包括接口测试、准确性测试和性能测试。

# 3 版本概要测试结论、关键风险和规避措施

## 3.1 测试结论总结

本报告主要测试Deep-Distill-Qwen-32B模型，128k长序列推理HBM资源的占用下降以及端到端吞吐量的提升。测试主要包括接口测试、准确性测试和性能测试。经测试HBM资源占用下降60%以上，端到端吞吐量提升2倍以上，符合验收标准。本次测试共执行1轮，未发现issue，整体质量良好。

## 3.2 约束说明

1、本特性暂时只支持Qwen2系列大模型。
2、本特性主要针对长序列推理场景。
3、本特性只支持运行在 NPU 加速卡上。
