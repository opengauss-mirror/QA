# 1 概述

本报告是针对 openGauss B 库带 dolphin 插件场景 TPCC 性能提升迭代的测试总结。
迭代修改的范围主要是 dolphin 插件，解决两个性能劣化问题：兼容性语法中表达式多层嵌套转换；外部库函数加载。

# 3 版本概要测试结论、关键风险和规避措施

## 3.1 测试结论总结

针对迭代 PR 合入前后的发布版本执行 TPCC 性能测试，验证其 OLTP 性能指标，执行 10 次。
确认迭代满足需求文档中的性能提升描述：

1. B 库 TPCC 2P 单机极限性能提升 15% 以上
2. B 库 TPCC 4P 单机极限性能提升 30% 以上

| 版本名称 | 用例 | TPCC 指标 |
| -------- | ---------------- | ---------- |
| 7.0.0-RC2 B019 | 非分区表 | 884,187.22 |
| 7.0.0-RC2 B020 | 非分区表 | 1,379,329.66 |
| 7.0.0-RC2 2025-08-20 | 分区表 | 1,193,848.78 |
| 7.0.0-RC2 2025-08-21 | 分区表 | 1,396,688.56 |

由于迭代不涉及功能特性与升级的修改，于是使用 CI 覆盖。

## 3.2 约束说明

- 仅对 B 库进行性能测试。
- 仅可在本测试场景中的整机条件下执行性能测试，其他配置可能无法达到预期效果。
