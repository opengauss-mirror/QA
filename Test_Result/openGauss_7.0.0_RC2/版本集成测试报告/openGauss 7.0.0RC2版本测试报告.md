# 1、概述

openGauss是一款全面友好开放，携手伙伴共同打造的企业级开源关系型数据库。openGauss提供面向多核架构的极致性能、全链路的业务、数据安全、基于AI的调优和高效运维的能力。openGauss具有高性能、高可靠、高安全和易运维等特性，深度融合华为在数据库领域多年的研发经验，结合企业级场景需求，持续构建竞争力特性。

openGauss 7.0.0 RC2版本新增内核场景化、工具链、资源池化和兼容性等特性，并对若干关键缺陷进行了修改。本文主要描述了openGauss 7.0.0 RC2版本整体测试情况，重点从特性质量、专项测试和问题单统计等维度展开叙述。综合来看，openGauss 7.0.0 RC2版本整体质量良好。

# 3、版本概要测试结论

openGauss 7.0.0 RC2版本整体测试按照release-manager团队的计划，版本测试规划采取21+3+2的测试方式，即21个B版本进行系统测试（内部21个版本，伙伴延期1个版本与集成测试并行）+3个B版本进行集成验证+2个B版本进行回归测试的策略，实际完成了21个B版本的系统测试+3个B版本的集成验证+并行5个B版本的回归测试：

openGauss 7.0.0 RC2 B001版本至openGauss 7.0.0 RC2 B010版本进行需求验收及问题单验收，主要涉及D库兼容性、黑匣子和向量数据库相关特性设计及验收，同时开展多轮的全量CI测试及专项测试，覆盖功能、可靠性、安全、性能、长稳、升级等测试。
