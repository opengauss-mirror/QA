# 1 概述
在数据库查询执行过程中，某些查询模式（尤其是嵌套循环连接 Nested Loop Join）可能会导致其子计划（特别是内表扫描）被重复执行多次。如果多次执行的输入参数是相同的，那么这些重复的计算就是一种资源浪费。
Memoize 最典型的应用场景是 Nested Loop Join 的内侧。开启参数enable_memoize，提升Nested Loop Joins性能。

# 3 版本概要测试结论、关键风险和规避措施

## 3.1 测试结论总结
需求共计执行11个用例，测试在不同数据库兼容性，不同表类型、视图及同义词、不同连接类型，聚集函数交互查询，单层嵌套，多层嵌套，pbe、函数、insert、update、事务中查询（强制nestloop）场景下，开启enable_memoize，Memoize节点缓存命中，查询效率优于enable_memoize关闭。

共发现2个问题单，已验证通过。整体质量良好。

## 3.2 约束说明

1.query_dop场景下禁用了memoize

2.列存表禁用了memoize
