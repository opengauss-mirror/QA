# 1 概述

此特性主要支持openGauss向量分布式能力，通过将数据进行分库分表来实现openGauss向量检索的scale out能力，突破单机物理资源的限制。涉及分布式表管理，分布式查询，分布式事务，DDL propagation，备份恢复，高可靠等能力。本次测试对象是未合入openGauss分支的个人仓develop版本，版本是基于0723时间点打的容器镜像Lite版本，无相关资料合入。

# 3 版本概要测试结论、关键风险和规避措施

## 3.1 测试结论总结

openGauss向量数据库支持分布式特性，共计涉及125条用例，主要覆盖安装部署-集群创建、正常场景、异常场景及约束场景验证，节点管理、节点信息查询验证、UDF管理验证，分片策略、分布式表管理、新增系统表查询验证、创建分布式表、修改分布式表、清理本地数据、分布式表转换为非分布式表验证，分布式事务、查看新增系统表pg_dist_transaction、pg_prepared_xacts正常和异常场景下表现，验证分布式查询的正常和异常场景表现，基本SQL语法覆盖验证，备份恢复功能正常和异常表现，验证内置函数和相关参数的表现，验证模块交互影响和兼容性测试。以上场景覆盖测试，主干功能表现正常，表现符合预期，其中测试过程中发现7个问题，待解决状态。本特性未合入主干分支，暂不进行升级测试和资料测试。测试结论：整体质量良好。

## 3.2 约束说明

- 仅支持向量表的分库分表
- 不支持分布式表相关复杂查询，不支持join
- 不支持分区表
- 不支持其他兼容性数据库（B,C,PG,D兼容性）
- 不支持线程池模式，启动异常
- CN节点不支持PBE优化
- 查询存在自定义函数、存储过程、包等不支持

## 3.3 关键风险和规避措施

无
