# 3 版本概要测试结论、关键风险和规避措施

## 3.1 测试结论总结

本报告主要测试openGauss支持的SDK多向量召回的功能，测试详情如下：

- 功能测试：输出测试用例130个；
- 长稳测试：覆盖python、c++、java、go、nodejs SDK接口；
- 可靠性测试：输出用例5个；
- 资料测试：覆盖企业版、轻量版资料。

需求覆盖100%，用例执行100%，总计发现issue共4个，4个问题待解决；开发质量一般。

## 3.2 约束说明

- 只支持python、java、c++、go、nodejs SDK。
- 支持语法：当前仅支持包含向量操作符(<->|<=>|<#>|<+>|<~>|<%>)的select开头的语句。

## 3.3 关键风险和规避措施
