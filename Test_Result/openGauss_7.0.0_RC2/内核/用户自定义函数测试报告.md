# 1 概述

本特性是opengauss数据库中，全模式下的数据库自定义函数结果缓存的支持，它支持语句级的结果缓存，自定义函数结果缓存在函数传入的参数值重复率高的场景下，能够起到较好的性能提升效果；在函数传入的参数值重复率不高的场景下，反而可能引起性能的劣化。
