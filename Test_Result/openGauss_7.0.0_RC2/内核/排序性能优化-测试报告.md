# 1 概述

此功能是加速排序算子性能，在内存不足需要落盘的场景下，改用kway merge进行归并计算，比原有polyphase merge算法性能有较明显提升。一般来说，在大数据量（10万条以上）的情况下，工作内存越小，性能改善越明显。在定长单列排序的场景下，通过缩短调用链路、优化单列数据结构、添加专用比较函数等方式，有效减少函数调用、内存拷贝和计算开销。

# 3 版本概要测试结论、关键风险和规避措施

## 3.1 测试结论总结
需求共计执行21个用例，测试在不同表类型、字段类型、不同数据量，特性交互查询场景下，进行单列排序，涉及落盘和定长单列场景下，排序算子性能提升30%以上。
work_mem越小，排序性能越好。
非落盘场景，部分字段排序算子性能也有提升。
创建索引场景（hash、btree、ubtree），有性能优化，但收益低于排序，且不是对所有字段有效。

## 3.2 约束说明

1.数据量较少场景下，有些字段可能走缓存不落盘，故对于有些字段类型，可能存在性能无提升的情况。
