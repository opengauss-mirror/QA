# 1   概述

支持bloom index，是数据库创建bloom类型索引。bloom索引是一种用于加速数据库查询的特殊类型的索引，基于bloom过滤器概念，用于在大型数据集上快速地判断某个元素是否存在于集合中。
在数据库中，bloom索引用于处理查询条件中包含大量重复值的情况。
举例：在某个列上存在大量相同值的情况下，bloom索引并不存储实际的索引值，而是适用bloom过滤器来快速判断某个值是否存在于索引中，从而减少了实际索引存储的大小和加速了查询的速度。
bloom索引在其with字句中接受以下参数：
length
	每个签名的长度，位为单位。将其舍入到最接近的16的倍数。默认值是80位，最大值是4096。
col1--col32
	每个索引列生成的位数。每个参数的名称值是控制的索引列的编号。默认值是2位，最大值是4095。未实际使用的索引列的参数将被忽略。

# 3   版本概要测试结论

openGauss 7.0.0-RC2 build 56967340版本测试阶段完成了基本功能测试、兼容性测试以及语法测试，性能测试。发现1个问题，无遗留风险，整体质量良好。

支持bloom index ，共计执行了200个用例，主要覆盖了基本功能测试、兼容性测试、异常测试以及资料测试。功能测试覆盖了多个基本测试点，行存的普通表，分区表，local临时表，global临时表，列存，搜索null值，搜索普通值，创建包含除int4和text外其他类型字段的索引；异常测试：修改文件权限；兼容性测试在其他兼容模式下执行；语法测试包括基础语法。测试中发现问题1个，无遗留问题整体质量良好。
